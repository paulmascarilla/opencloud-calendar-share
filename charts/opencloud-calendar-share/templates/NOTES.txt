Invitations created in CalDAV clients (guests added by e-mail in Thunderbird, DAVx⁵…) are disabled.
To enable them, create a plain OpenCloud user (e.g. "calshare-bot"), give it an app token and store it:
  opencloud auth-app create --user-name=calshare-bot --expiration=8760h
  kubectl -n {{ .Release.Namespace }} create secret generic calshare-service --from-literal=auth=calshare-bot:<token>
then set calshare.serviceAccount.existingSecret=calshare-service.
